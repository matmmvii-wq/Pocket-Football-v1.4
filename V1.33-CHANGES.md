# Pocket Football v1.33 — crossbar physics correction

- Removed the special bot AI roof-sweep routine. The bot no longer changes its targets to climb onto a goalpost to free the ball.
- The ball physics alone now handles crossbar stalls: after 0.3 seconds near-stationary on the roof, the ball is nudged toward the pitch until it clears the crossbar. Normal rebounds are unaffected.
- Preserved the v1.32 restart and input protections.

Build note: Rebuild with `npm ci && npm run build` if you edit source.
